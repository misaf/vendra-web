# Reporting

Reporting modules expose audit and authentication activity inside the admin
panel.

## Activity Log

Module: `misaf/vendra-activity-log`

Resources:

- Activity Logs

The module is built around Spatie Activity Log and provides tenant-scoped
records in the admin panel.

## Authify Log

Module: `misaf/vendra-authify-log`

Resources:

- Authify Logs

Authify logs track authentication-related activity and appear under report
management.

## Transaction widgets

The main app also defines admin widgets for transaction deposit, withdrawal,
bonus, and latest transaction reporting.
