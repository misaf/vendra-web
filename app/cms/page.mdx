# Vendra CMS

The Vendra CMS is the Filament admin experience for the main Laravel
application.

## Admin panel

The admin panel is registered in `App\Providers\Filament\AdminPanelProvider`.
It is available at `/admin`, runs with tenant middleware, and uses strict
authorization.

## Navigation groups

- User Management
- Billing Management
- Transaction Management
- Content Management
- Report Management
- Setting Management

## Main areas

- [Content Management](/cms/content-management)
- [Commerce](/cms/commerce)

## Tenant awareness

The admin panel uses `Tenant::class` as its Filament tenant model and applies
Spatie multitenancy middleware. Most CMS modules are tenant-scoped.
