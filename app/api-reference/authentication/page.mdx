# Authentication

The inspected JSON:API servers return `authorizable(): false`.

## Current behavior

- API routes are registered with Laravel's `api` middleware group.
- JSON:API server-level authorization is disabled in the inspected modules.
- Public resources are read-only.

## Modules checked

- `vendra-blog-api`
- `vendra-faq-api`
- `vendra-product-api`
- `vendra-multimedia-api`

If write endpoints or protected endpoints are added later, this page should
document Sanctum tokens, required headers, and per-resource authorization rules.
