# API Reference

Vendra API modules use Laravel JSON:API and expose read-only resources under
`/api/v1`.

## Start here

- [Endpoints](/api-reference/endpoints)
- [Authentication](/api-reference/authentication)
- [Errors](/api-reference/errors)

## What belongs here

- Blog JSON:API resources
- FAQ JSON:API resources
- Product JSON:API resources
- Multimedia JSON:API resources
- Error handling behavior

## Servers

- `vendra-blog`
- `vendra-faq`
- `vendra-product`
- `vendra-multimedia`

Each inspected server uses `baseUri = '/api/v1'` and `authorizable(): false`.
