## TLS and headers

Public deployments use ACME. Local deployments use a persistent generated CA.

<DefList
  items={[
    {
      term: 'HSTS',
      description:

    },
    {
      term: 'includeSubDomains',
      description:
        'Applied to platform subdomains. Customer storefront domains do not receive it.'
