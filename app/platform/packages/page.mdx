## Package conventions

<DefList
  items={[
    {
      term: 'README is the contract',
      description:
        'Each package README is its user-facing feature and usage contract.'
    },
    {
      term: 'Publish only what is documented',
      description:
        'Package resources and configuration are published only when documented.'
    },
    {
      term: 'Shared navigation taxonomy',
      description:
        'Filament resources use the shared cluster and navigation taxonomy from Support.'
    },
    {
      term: 'One domain model',
      description:
        'API packages map domain objects to API Platform resources. They do not invent a second domain model.'
    },
    {
      term: 'Contracts over concretes',
      description:
        'Tenant-aware behavior is activated through contracts rather than hard-coded dependencies on the concrete tenant provider.'
    }
  ]}
/>

For implementation details, read the package’s own README and tests in the
platform repository.
