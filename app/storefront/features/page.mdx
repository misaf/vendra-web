# Features and limits

## API-backed surfaces

- Product listing, categories, detail pages, and related products
- Blog listing, posts, categories, and related posts
- FAQ categories, search, and filtering
- Localized metadata, sitemap, robots, and structured data

## Browser-local demo surfaces

Cart, favorites, and order history are stored in `localStorage`. The account
panel is not authentication. Checkout creates only local demo order state and
does not submit payment or order data to Laravel. Newsletter submission is also
a simulated flow.

Do not represent these surfaces as production commerce integrations or collect
real payment data through them.

## Localization and themes

The bundled locales are `en` and `fa`; more may be added. User-visible changes
normally require updates to both base catalogs. Property-specific wording belongs
in runtime message overrides.

The current published theme is `default`. Theme composition is selected when the
image is built, while property branding is supplied at runtime. Supporting a
second theme requires adding its page exports and publishing a compatible image;
it is not a visitor-facing runtime toggle.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
# or all three
npm run check
```

Verify public UI in English and Persian, RTL, responsive layouts, accessibility,
and both light and dark color schemes.
