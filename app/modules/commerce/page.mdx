# Commerce Modules

## `misaf/vendra-product`

Product catalog management.

Repository: [misaf/vendra-product](https://github.com/misaf/vendra-product)

- Product Categories
- Products
- Product Prices
- Product pricing actions
- API package: `misaf/vendra-product-api`

## `misaf/vendra-currency`

Currency and currency category management.

Repository: [misaf/vendra-currency](https://github.com/misaf/vendra-currency)

- Currency Categories
- Currencies
- Buy price, sell price, and default currency actions

## `misaf/vendra-transaction`

Transaction and gateway management.

Repository: [misaf/vendra-transaction](https://github.com/misaf/vendra-transaction)

- Transactions
- Transaction Gateways
- Transaction metadata, limits, fees, transfers, and checks
- Types: deposit, withdrawal, commission, bonus, transfer
- Statuses: approved, declined, failed, pending, review, processing

## `misaf/vendra-affiliate`

Affiliate and referral management.

Repository: [misaf/vendra-affiliate](https://github.com/misaf/vendra-affiliate)

- Affiliates
- Affiliate Users
- Affiliate policies and relation managers
