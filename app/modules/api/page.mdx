# API Modules

The API modules use Laravel JSON:API and expose read-only public resources under
`/api/v1`.

## `misaf/vendra-blog-api`

Server: `vendra-blog`

Repository: [misaf/vendra-blog-api](https://github.com/misaf/vendra-blog-api)

Resources:

- `blog-post-categories`
- `blog-posts`

Relationships:

- Blog categories have many blog posts and multimedia
- Blog posts have one category and many multimedia

## `misaf/vendra-faq-api`

Server: `vendra-faq`

Repository: [misaf/vendra-faq-api](https://github.com/misaf/vendra-faq-api)

Resources:

- `faq-categories`
- `faqs`

Relationships:

- FAQs have one FAQ category and many multimedia
- FAQ categories expose FAQ and multimedia relationships

## `misaf/vendra-product-api`

Server: `vendra-product`

Repository: [misaf/vendra-product-api](https://github.com/misaf/vendra-product-api)

Resources:

- `product-categories`
- `products`
- `product-prices`

Relationships:

- Products have one category, many prices, one latest price, and many multimedia
- Product categories have many products, product prices, and multimedia
- Product prices have one product

## `misaf/vendra-multimedia-api`

Server: `vendra-multimedia`

Repository: [misaf/vendra-multimedia-api](https://github.com/misaf/vendra-multimedia-api)

Resources:

- `multimedia`

## Authorization

The inspected API servers return `authorizable(): false`, so these resources are
not authorizable at the JSON:API server level.
