# Modules

Vendra modules are first-party Composer packages maintained and supported by
you. The root app requires them as `misaf/*` packages, while local development
uses Composer path repositories pointed at `app-modules/*`.

Canonical GitHub repositories use this pattern:

```txt
https://github.com/misaf/<module-name>
```

For example:

- `https://github.com/misaf/vendra-transaction`
- `https://github.com/misaf/vendra-permission`
- `https://github.com/misaf/vendra-blog`

The inspected first-party module source is under:

```txt
/Users/misaf/Documents/Projects/vendra/app-modules.bk
```

## First-party package pattern

Most modules provide some combination of:

- Filament plugin
- Service provider
- Eloquent models
- Filament resources or clusters
- Policies and permission enums
- Migrations and seeders
- Translation files
- Tests and static analysis config
