# Users & Permissions Modules

## `misaf/vendra-user`

Base user module.

Repository: [misaf/vendra-user](https://github.com/misaf/vendra-user)

- User model
- User Filament plugin
- User policy and feature enum

## `misaf/vendra-user-profile`

User profile management.

Repository: [misaf/vendra-user-profile](https://github.com/misaf/vendra-user-profile)

- User Profile model
- User Profile Filament resource
- User profile policy and feature enum

## `misaf/vendra-user-profile-phone`

Expanded user/profile module with phone, document, and balance resources.

Repository: [misaf/vendra-user-profile-phone](https://github.com/misaf/vendra-user-profile-phone)

- Users
- User Profiles
- User Profile Phones
- User Profile Documents
- User Profile Balances

## `misaf/vendra-user-profile-document`

Profile document and verification-oriented resources.

Repository: [misaf/vendra-user-profile-document](https://github.com/misaf/vendra-user-profile-document)

- User Profile Documents
- User Profile Phones
- User Profile Balances
- Approved, pending, and rejected status states

## `misaf/vendra-permission`

Role and permission management.

Repository: [misaf/vendra-permission](https://github.com/misaf/vendra-permission)

- Roles
- Permissions
- Spatie Permission integration
- Laravel Pennant feature gates
- Tenant-scoped feature toggle command
