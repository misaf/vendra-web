# Production host

## Prepare infrastructure

Install Docker Engine, Docker Compose v2, and a versioned `vendra` CLI binary.
Point the base domain plus `api`, `admin`, `console`, and `reseller` hosts to the
server. Each customer domain must also resolve to it.

## Controller configuration

Create `/etc/vendra/controller.yaml` using immutable image digests:

```yaml
state_dir: /var/lib/vendra
base_domain: example.com
network: traefik-public
listen: :8080
health_timeout: 2m
certificate_mode: acme
acme_email: ops@example.com
images:
  platform: ghcr.io/your-org/vendra@sha256:PLATFORM
  website: ghcr.io/your-org/vendra-website@sha256:WEBSITE
  storefront: ghcr.io/your-org/storefront@sha256:STOREFRONT
  provisioner: ghcr.io/your-org/vendra-controller@sha256:PROVISIONER
```

Place `APP_KEY`, database credentials, mail settings, and
`VENDRA_PROVISIONER_TOKEN` in `/etc/vendra/controller.env`, owned by root with
mode `0600`. Do not put secrets in YAML.

## Initialize and verify

```bash
sudo vendra init --config /etc/vendra/controller.yaml
sudo vendra stack up --config /etc/vendra/controller.yaml
sudo vendra stack status --config /etc/vendra/controller.yaml
sudo vendra stack urls --config /etc/vendra/controller.yaml
```

Re-running `stack up` is the normal convergent operation after configuration or
image changes.
