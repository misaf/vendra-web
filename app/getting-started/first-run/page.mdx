# First Run

Use this page for the first successful launch after setup.

## Verify the basics

Start the Vendra app:

```bash
composer dev
```

`composer dev` starts the Laravel server, queue listener, logs, and Vite watcher.

Then verify:

- The application loads.
- `/admin` opens the admin panel.
- `/user` opens the user panel.
- Queue and log processes stay running.
- Filament package discovery has completed.
