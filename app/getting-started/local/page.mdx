# Local ecosystem

This workflow runs locally built images behind the same Traefik topology used in
production. Use explicit local tags and disable controller pulls.

## Build images

```bash
docker build -t vendra-controller:local ./vendra-controller
docker build -t vendra-storefront-florist:local ./vendra-storefront-florist
docker build -f vendra/docker/Dockerfile -t vendra-platform:local ./vendra
```

## Configure the controller

```yaml
state_dir: /absolute/writable/path/vendra-state
base_domain: vendra.test
network: traefik-public
certificate_mode: self-signed
images:
  platform: vendra-platform:local
  website: ""
  storefront: vendra-storefront-florist:local
  provisioner: vendra-controller:local
no_pull: true
```

`no_pull: true` matters for console-driven provisioning because the provisioner
runs without CLI flags. Local tags must exactly match the names in this file.

## Start and resolve hosts

```bash
vendra init --config ./controller.local.yaml
vendra stack up --no-pull --config ./controller.local.yaml
sudo vendra stack hosts --write --config ./controller.local.yaml
```

In self-signed mode, accept or trust the generated authority for both
`https://api.vendra.test` and the storefront domain. A page may render while
browser API calls fail TLS, producing deceptively empty sections.
