## Requirements by workflow

| Workflow | Requirements |
| --- | --- |
| Laravel development | PHP 8.3+, Composer, Node.js/npm, supported database |
| Storefront development | Node.js/npm; canonical API optional for UI-only work |
| Controller development | Go version from `go.mod`, Docker Compose v2 |
| Production host | Linux, Docker Engine, Compose v2, `vendra` binary, DNS, registry access |
