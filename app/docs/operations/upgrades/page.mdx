## Platform upgrade

```bash
composer update --with-all-dependencies
php artisan migrate --force
php artisan optimize:clear
composer test
composer stan
```

Keep first-party Vendra packages on the same release line. Review
package-specific instructions before publishing configuration or assets.

## Order of deployment

<Callout type="warning">
  Prefer backward-compatible consumers first. Deploy code that accepts both old
  and new fields **before** producers begin sending only the new contract.
</Callout>
