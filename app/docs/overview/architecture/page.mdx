# Architecture

<Lede>
  One public edge, one canonical API, and a deliberately asynchronous
  provisioning path. This page describes how a request reaches a storefront and
  which system owns each piece of state.
</Lede>

## Request path

Traefik is the only public edge. It terminates TLS and routes the platform hosts
and customer storefront domains. A storefront serves pages from its own Next.js
container and reads commerce and content data from the canonical Laravel API.

<Panel title="How a page is served" className="space-y-5">

The browser never talks to the canonical API directly. Routing every client read
through the same-origin proxy keeps API origins and the optional storefront
credential out of the JavaScript bundle.

## Provisioning path

Creating a property is intentionally asynchronous.

<Steps
  items={[
    {
      title: 'Laravel records desired state',
      body: 'It creates the tenant and a durable StorefrontDeployment record before any container exists.'
    },
    {
      title: 'A queued job calls the provisioner',
      body: 'The job sends an authenticated request to the Go provisioner.'
    },
    {
      title: 'The provisioner validates',
      body: 'It checks request identity and every field required for the storefront to boot. The image applies the complete schema during its readiness check.'
    },
    {
      title: 'The controller renders and starts',
      body: 'It writes a per-property Compose project, pulls the image, and waits for /api/health.'
    },
    {
      title: 'Laravel records the result',
      body: 'It stores the returned status, controller reference, and resolved image digest.'
    }
  ]}
/>

<Callout type="warning">
  The Laravel web process never receives the Docker socket. Only the provisioner
  can mutate Docker state.
</Callout>

## State ownership

| State | Owner | Recovery source |
| --- | --- | --- |
| Tenants, domains, billing, deployment requests | Laravel database | Database backup |
| Host config and secrets | Operator | `/etc/vendra` backup or secret manager |
| ACME account/certificates | Controller state | `<state_dir>/acme` backup |
| Generated Compose/property files | Controller | Re-render and reconcile |
| Cart, favorites, demo orders | Visitor browser | Not durable server state |
