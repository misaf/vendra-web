# Go controller

<Lede>
  `vendra-controller` is Vendra’s infrastructure control plane. It is the only
  component allowed to mutate Docker state on a host.
</Lede>

## Two binaries, shared internals

drift apart in how they render or start a property.

Generated runtime state lives under `state_dir`, which defaults to
`/var/lib/vendra`.

<Callout type="warning">
  Do not edit embedded or rendered Compose manifests directly. Rendering
  replaces them, and your changes will disappear on the next `stack up`.
</Callout>

## Build locally

```bash
cd vendra-controller
go build -o ./bin/vendra ./cmd/vendra
./bin/vendra version
go test ./...
```

Production hosts should install a versioned binary artifact rather than a source
checkout and Go toolchain.
