# Configuration

<Lede>

  the one earlier in this chain wins.
</Lede>

    },
    {
      term: 'images.*',
      description:

    },
    {
      term: 'no_pull',
      description:
        'Use locally available application images instead of explicit pulls.'
    }
  ]}
/>

Use digest-pinned images in production. A property’s request-level image
overrides the fallback storefront image, which lets different storefront digests
coexist on one host.

## Secrets

Store secrets in `/etc/vendra/controller.env` with mode `0600`:

<DefList
  items={[
    {
      term: 'VENDRA_PROVISIONER_TOKEN',
      description: 'Shared bearer token between Laravel and the provisioner.'
    },
    { term: 'APP_KEY', description: 'Laravel application key.' },
    { term: 'Database credentials', description: 'MySQL user and password.' },
    {
      term: 'Mail and other runtime secrets',
      description: 'Anything the platform containers need at runtime.'
    }
  ]}
/>

Process environment values override this file.

<Callout type="error">
  Never commit `controller.env`, and never place secrets in `controller.yaml`.
</Callout>
