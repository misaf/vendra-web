<Lede>
  The controller turns Laravel's desired storefront state into a running,
  healthy Compose project. This page explains that lifecycle and who owns each
  step; the API Reference owns the wire contract.

The currently accepted template family is `vendra-storefront-florist`. A
request can select a different compatible image digest per property. Property
and certificate mutations are serialized so concurrent requests cannot rewrite
the same controller state.

## Deployment states

<Flow
  label="Successful path"
  nodes={['requested', 'queued', 'provisioning', 'healthy']}
/>

Laravel owns `requested`, `queued`, retry, and terminal deployment records. The
controller observes one request at a time and returns only after Compose reports
the storefront healthy. A failed request returns to Laravel as an error; Laravel
decides whether and when it becomes `retrying`.
