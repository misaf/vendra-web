# Next.js storefront

<Lede>
  `vendra-storefront-florist` is a bilingual English/Persian storefront template
  built with Next.js 16 and React 19. Persian (`fa`) is the default locale and
  the first route segment.
</Lede>

<Tag tone="emerald">Runtime-configured</Tag> <Tag>Theme-composed at build</Tag>

One shared production image serves every property. Identity arrives at container
start, never at build time.

Code outside a feature module imports through that module’s `index.ts`. Shared
code and base messages must remain property-neutral. Persian routes preserve RTL
behavior and use a Persian UI font.

## Data path

Server components call the canonical API directly. Everything the browser reads
goes through a same-origin route instead.

<Panel title="Browser routes" className="space-y-5">
  <Flow label="Data reads" nodes={['Browser', '/api/proxy/*', 'Canonical API']} />
  <Flow label="Media" nodes={['Browser', '/api/storage/*', 'Storage origin']} />
  <Flow
    label="Checkout map picker"
    nodes={['Browser', '/api/geocode/reverse', 'Geocoding service']}
  />
</Panel>

This keeps API and storage origins — and the optional `X-Storefront-Key`
credential — out of the browser bundle.

The image exposes `/api/health`, which Docker and Traefik both check.
