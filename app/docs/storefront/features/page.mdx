<Callout type="error">
  Do not represent the demo surfaces as production commerce integrations, and do
  not collect real payment data through them. Checkout does not submit payment or
  order data to Laravel.
</Callout>

## Localization

The bundled locales are `en` and `fa`, and more may be added. User-visible
changes normally require updates to both base catalogs. Property-specific wording
belongs in runtime message overrides, not the base catalog.

## Themes

The current published theme is `default`.

<Flow
  label="Where each decision is made"
  nodes={['Theme composition — build time', 'Property branding — runtime']}
/>

Supporting a second theme requires adding its page exports and publishing a
compatible image. It is not a visitor-facing runtime toggle.
