# Build and deployment

<Lede>
  The published container is tenant-neutral. One image serves the whole fleet,
  and property identity arrives only at container start.
</Lede>

## Shared image model

  doTitle="Safe as build arguments"

```bash
docker build \
  --build-arg NEXT_PUBLIC_MAP_PROVIDER=osm \
  -t ghcr.io/your-org/vendra-storefront:<version> .
docker push ghcr.io/your-org/vendra-storefront:<version>
```

<Callout type="warning">
  Deploy the resulting digest, not a moving tag. A tag that moves underneath a
  running fleet makes rollbacks guesswork.
</Callout>

## Controller integration

The production property Compose template is embedded in the controller binary.
It injects property configuration, the canonical API URL, optional integrations,
certificate trust, health checks, and Traefik labels.

<Callout type="info">
  This repository’s own Compose file is local integration tooling, not a
  competing production definition.
</Callout>

## Update a property

```bash
vendra property render <slug> <domain> \
  --image ghcr.io/your-org/storefront@sha256:<new-digest> \
  --configuration /tmp/<slug>.json
vendra property restart <slug>
```

## Removal is not deletion

Removing controller state does not delete the backend tenant. Deleting a tenant
is a separate business-data operation from stopping its storefront.
