# About Vendra

Vendra is a modular Laravel CMS and marketplace framework.

The main application lives at `/Users/misaf/Documents/Projects/vendra`. It uses
Laravel 13, Filament 5, Sanctum, Horizon, Spatie packages, and a set of
first-party Composer modules maintained and supported by you. The inspected
module source currently lives under `app-modules.bk`.

## Runtime stack

- PHP 8.3+
- Laravel 13
- Filament 5
- Laravel Sanctum
- Laravel Horizon
- Spatie Media Library, Settings, Permissions, Activity Log, and Multitenancy
- Laravel JSON:API packages for public read-only resources

## Panels

Vendra has two Filament panels:

- `admin` at `/admin`
- `user` at `/user`

The admin panel is tenant-aware and uses navigation groups for users, billing,
transactions, content, reports, and settings. The user panel handles user-facing
profile, dashboard, billing, and account workflows.

## Module model

Modules are first-party Laravel components. The root app requires them as
`misaf/*` Composer packages, and local development is configured through path
repositories that point at `app-modules/*`.

Each module typically owns:

- Filament resources or clusters
- Eloquent models
- Policies and permission enums
- Migrations and seeders
- Translation files
- Optional API package
