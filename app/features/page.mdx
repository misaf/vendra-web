# Features

Vendra features are delivered through Laravel modules and Filament resources.

## Feature areas

- Tenant-aware admin panel
- Content management for blogs, custom pages, FAQs, media, tags, and languages
- Product, currency, transaction, and affiliate management
- User, profile, role, permission, and feature-gate management
- Activity and authentication reporting
- Public read-only JSON:API modules

## Admin navigation groups

The admin panel groups resources under:

- User Management
- Billing Management
- Transaction Management
- Content Management
- Report Management
- Setting Management

## API coverage

API modules expose read-only JSON:API resources for public content and catalog
data:

- Blog posts and blog post categories
- FAQ items and FAQ categories
- Products, product categories, and product prices
- Multimedia assets
