# Operations runbook

<Lede>
  Day-to-day checks, what must be backed up, and the order to restore things in
  when a host is lost.
</Lede>

## Daily checks

<CommandList
  items={[
    { cmd: 'vendra stack status', description: 'Overall stack health.' },
    { cmd: 'vendra stack ps', description: 'Container-level state.' },
    {
      cmd: 'vendra property ls',
      description: 'Property inventory and registry drift.'
    },
    {
      cmd: 'vendra stack logs <service>',
      description: 'Investigate anything reported unhealthy.'
    }
  ]}
/>

<Callout type="info">
  A storefront must pass **both** its Docker health check and Traefik’s
  `/api/health` probe. One passing without the other still means the property is
  not serving correctly.
</Callout>

## Backup scope

<DefList
  items={[
    {
      term: 'Laravel database and media',
      tag: { tone: 'red', label: 'Authoritative' },
      description: 'Cannot be reconstructed from anything else.'
    },
    {
      term: '/etc/vendra/controller.yaml + secrets',
      tag: { tone: 'red', label: 'Authoritative' },
      description: 'Host desired state and protected environment values.'
    },
    {
      term: 'Controller ACME state',
      tag: { tone: 'amber', label: 'Continuity' },
      description: 'Certificate and account continuity across rebuilds.'
    },
    {
      term: 'Image digests + binary version',
      tag: { tone: 'amber', label: 'Continuity' },
      description: 'The tested compatibility set you are running.'
    }
  ]}
/>

Generated Compose manifests can be recreated.

<Callout type="warning">
  The safe property registry cannot recreate encoded property configuration by
  itself. Laravel’s deployment records remain authoritative — back up the
  database, not just the registry.
</Callout>

## Recovery outline

<Steps
  items={[
    {
      title: 'Restore state',
      body: 'Database, media, configuration, secrets, and ACME state.'
    },
    {
      title: 'Install the matching vendra binary',
      body: 'Match the version that produced the state you restored.'
    },
    {
      title: 'Run vendra stack up',
      body: 'Then verify platform health before going further.'
    },
    {
      title: 'Reconcile storefront deployments from Laravel',
      body: 'This replays the fleet from authoritative records.'
    },
    {
      title: 'Verify end to end',
      body: 'Domains, certificates, tenant-specific API data, and both locales.'
    }
  ]}
/>
