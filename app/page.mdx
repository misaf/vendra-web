## System at a glance

```text
Visitors ──HTTPS──> Traefik ──> Next.js storefront ──> canonical Laravel API
Operators ────────> vendra CLI ──> Docker Compose projects
Laravel queue ────> provisioner API ──> per-property storefront containers
```

Laravel owns business state. The controller owns host runtime state. The
storefront owns presentation and browser-local demo state. Keeping those
boundaries explicit is the central architectural rule.

## Current stack

- Platform: PHP 8.3+, Laravel 13, Filament 5, Livewire 4
- Controller: Go, Docker Engine, Docker Compose v2, Traefik
- Storefront: Next.js 16, React 19, TypeScript, Tailwind CSS 4
- Documentation: Next.js 16, Nextra 4
